# Vueling Inflight Experience

**An AI-powered backend that turns every Vueling flight into a personalised digital journey.**

Passengers scan their boarding pass and instantly get destination highlights, restaurant picks, weather forecasts, curated news, crew introductions, and aircraft details — all generated by AI, translated into their language, and delivered through a single API call.

Built as a proof of concept for **MWC Barcelona 2026**.

---

## Why This Exists

Passengers sit idle for 1-3 hours with zero engagement from the airline. No personalised content, no destination guidance, no connection between the flight and where they're going. Competitors are investing in digital experiences — this PoC proves Vueling can lead with AI.

---

## What It Does

One booking number in, a complete experience out:

| Pillar | What the passenger gets |
|---|---|
| **Discover Your Destination** | Top 5 highlights + 3 restaurant picks, AI-generated in their language |
| **Getting to the City** | Airport-to-city transport options (train, bus, taxi) with times and tips |
| **Your Aircraft** | Model, name ("Spirit of Barcelona"), registration, age |
| **Your Crew** | Captain and first officer by name, cabin crew by first name (privacy) |
| **Weather** | 3-day forecast from OpenWeatherMap (fallback: mock data) |
| **Local News** | 5 curated headlines from NewsAPI, filtered for inflight safety (no violence, disasters) |
| **Peace of Mind** | Emergency contacts (police, ambulance, taxi, Vueling helpline) |

All of this is returned by a single endpoint: `GET /api/v1/inflight-experience/{booking}/{language}`

---

## Tech Stack

| Layer | Technology |
|---|---|
| **Framework** | FastAPI (Python 3.11) |
| **AI Content** | Google Gemini 2.5 Flash — generates highlights, restaurants, transport, translations |
| **Weather** | OpenWeatherMap API (real data with mock fallback) |
| **News** | NewsAPI.org (real articles, Python-side safety filtering, Gemini fallback) |
| **Data** | Pydantic v2 schemas, CSV mock data via pandas |
| **Testing** | pytest + pytest-cov (99 tests, 81% coverage) |
| **Languages** | 6 supported: es, en, fr, it, ca, gl |

## Quick Start

```bash
# Clone and setup
git clone https://github.com/gelilho/inflight-poc.git
cd inflight-poc
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt

# Configure (minimum: Gemini API key)
cp config/environments/.env.template .env
# Edit .env and add your GEMINI_API_KEY

# Run
scripts/run.sh
# API docs at http://localhost:8000/docs
```

### Try It

```bash
# Full experience for passenger Angel, flight to Rome, in Spanish
curl http://localhost:8000/api/v1/inflight-experience/VY4K7M/es | jq '.'

# Just the flight details
curl http://localhost:8000/api/v1/flight/VY71299/20260207 | jq '.'

# Destination content for Rome in Italian
curl http://localhost:8000/api/v1/destination/FCO/content/it | jq '.'
```

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/v1/inflight-experience/{booking}/{lang}` | Complete experience (the "big flow") |
| `GET` | `/api/v1/passenger/{user_id}` | Passenger info |
| `GET` | `/api/v1/passenger/{user_id}/bookings` | All bookings for a passenger |
| `GET` | `/api/v1/booking/{booking_number}` | Booking details |
| `GET` | `/api/v1/flight/{flight_number}/{date}` | Flight operations (crew, aircraft, gates) |
| `GET` | `/api/v1/destination/{airport}/content/{lang}` | AI-generated destination content |
| `GET` | `/api/v1/destination/{airport}/weather/{lang}` | 3-day weather forecast |
| `GET` | `/api/v1/destination/{airport}/news/{lang}` | Curated local news |
| `GET` | `/health` | Health check |

Interactive docs available at `/docs` when the server is running.

## Resilience

Every external dependency has a fallback:

| Source | Primary | Fallback |
|---|---|---|
| Destination content | Gemini AI | Static defaults (5 highlights, 3 restaurants, taxi) |
| Weather | OpenWeatherMap API | Mock forecast data |
| News | NewsAPI.org | Gemini-generated safe news |
| Translation | Gemini AI | Returns English original |
